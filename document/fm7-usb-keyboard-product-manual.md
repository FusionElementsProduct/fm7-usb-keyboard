# 製品仕様書兼取扱説明書

**FM-7 Keyboard to USB Converter Type RPPico**  
ブランド：**Fusion Elements**  
製品番号：**FM7USBKB-001**  
対象基板：**Rev 0.5**  
文書版：**1.0（試作版）／2026年10月4日**

本書は、FM-7キーボードをUSBキーボードとして使用する変換基板の仕様と操作方法をまとめたものです。

## 1. 製品概要

FM-7実機から取り外したキーボードユニットを、Raspberry Pi Picoを介してUSB HIDキーボードに変換します。キーボードの34ピンフラットケーブルを本基板に接続し、PicoのUSB端子からホスト機器へ接続します。

- FM-7のキー入力をUSBで送信します。
- FM-7エミュレータ向け・Windows向け・Mac向けのキー割当を切り替えられます。
- CAPS・かなランプをホストからの状態通知に応じて制御します。
- 標準ファームウェアは、FM-7エミュレータの受信形式に合わせた6KRO方式です。

本機はキーボードユニット用の変換基板です。FM-7本体の動作をUSBへ変換するものではありません。「FM7モード」は shippoiincho氏の [fm7emulator](https://github.com/shippoiincho/fm7emulator) のキー割り当てを意味し、FM-7本体へのUSB接続を意味しません。

## 2. 製品仕様

| 項目 | 仕様 |
|---|---|
| 対象キーボード | FM-7実機キーボードユニット、34ピン接続 |
| 制御モジュール | 純正Raspberry Pi Pico（RP2040）。ソケット実装 |
| ホスト接続 | Pico上のUSB Micro-B端子 |
| USB機能 | USB HIDキーボード |
| 製品名 | `FM7USBKB-001` |
| 電源 | USBバスパワー、VBUS 5V。外部電源入力なし |
| キーマトリクス | SCAN 16本 × SENSE 7本、BREAKは独立入力 |
| 標準同時入力形式 | 一般キー最大6コード＋修飾キー（6KRO）。組み合わせによる制限あり |
| 拡張同時入力形式 | 別ファームウェアによるNKRO形式。全キー同時入力を保証するものではありません |
| 対応ランプ | CAPS・かな。INSERTランプは未対応（INS状態はPico本体のLEDで代用表示） |
| モード | FM7／Windows／Mac。設定を不揮発保存 |
| 初期モード | 有効な保存設定がない場合はFM7 |
| 基板外形 | 53.34 × 97.79 mm、四隅R3.1 mm相当 |
| 基板構成 | 2層、全スルーホール部品 |
| 取付穴 | M3用、直径3.2 mm、非メッキ、4か所 |
| 固定部品の目安 | ネジ頭・ワッシャ外径7.5 mm以下（設計上のJ3との干渉条件） |

基板寸法はPico、コネクタ、ケーブルなどの突出部を含みません。消費電流、完成状態の高さ・重量、使用温湿度範囲およびOSバージョン別の適合範囲は、本版では規定していません。

FM-8など、同じピン数でも配線が異なるキーボードは対象外です。Pico互換ボードやPico 2への差し替えは本書の対象外です。

## 3. 使用前の準備

### 必要なもの

- 実装済みのFM7USBKB-001 Rev 0.5基板
- ピンヘッダ実装済みの純正Raspberry Pi Pico（Pico Hを含む）
- FM-7キーボードユニットと対応する34ピンフラットケーブル（FM-7に付属）
- データ通信対応のUSBケーブル（Pico側Micro-B）
- USBホスト機器
- 基板を絶縁して固定できるスペーサ、ケースなど

### 接続・取り扱い上の注意

- 34ピンケーブル、Pico、部品を抜き差しするときは、USBを外してください。
- キーボードユニットはFM-7本体のマザーボードから切り離して使用してください。FM-7側と本基板を同時に接続しないでください。
- 34ピンコネクタはピン1と極性ガイドを確認し、逆挿し・1列ずれ・1ピンずれのない状態で接続してください。ケーブルの色だけで向きを判断しないでください。
- Picoは基板のピン配置に合わせて取り付けてください。向きが判断できない場合は、組立資料と照合してから通電してください。
- 基板裏面を金属面に直接置かないでください。固定時は、ネジ・スペーサ・ワッシャが配線や部品の端子に触れないようにしてください。
- USB以外から電源を加えないでください。Picoの信号端子へ5Vを接続しないでください。
- 異常な発熱、におい、煙がある場合は、直ちにUSBを抜き、実装と配線を確認してください。

## 4. 接続と使い始め方

1. USBが外れていることを確認します。
2. PicoがJ1・J2のソケットに正しく取り付けられていることを確認します。
3. FM-7キーボードの34ピンケーブルをJ3へ接続します。J3のキー溝は基板下端側です。ピン1の対応も確認してください。
4. 基板を絶縁された場所に固定します。
5. Picoに通常用ファームウェアが書き込まれていることを確認します。未書き込みの場合は第10章を参照してください。
6. PicoのMicro-B端子とホスト機器をUSBケーブルで接続します。
7. CAPS・かなランプの起動時点滅で保存済みモードを確認し、必要に応じて第5章の操作で変更します。
8. テキストエディタなどを開き、英数字、Enter、Backspace、矢印キーを一つずつ確認します。

通常使用はUSB HIDキーボードとして行います。専用の常駐アプリは使用しません。ホスト側のキーボード配列は日本語（JIS）を前提に調整してください。実際に入力される文字やショートカットの動作は、OS、入力ソース、アプリの設定によって異なります。

使用を終えるときはUSBを抜きます。選択したモードは電源を切っても保持されます。

## 5. ホストモードの切替

ほかのキーを離し、**CTRLとGRAPHを押したまま、目的のPFキーを押してから、すべてのキーを離します。**

| 操作 | 選択モード | CAPS・かなランプの同時点滅 |
|---|---|---|
| CTRL ＋ GRAPH ＋ PF1 | FM7 | 1回 |
| CTRL ＋ GRAPH ＋ PF2 | Windows | 2回 |
| CTRL ＋ GRAPH ＋ PF3 | Mac | 3回 |

選択したモードは保存され、次回起動時にも同じ回数で点滅します。USBの抜き差しは不要です。切替に使ったPFキーは、通常のF1～F3入力として送信されません。

モードによって変わる主な操作は、KANAキーとGRAPHを組み合わせた日本語入力切替です。英数字や通常の編集キーの割当は共通です。

| キー・操作 | FM7モード | Windowsモード | Macモード |
|---|---|---|---|
| CTRL | 左Control | 左Control | 左Control |
| SHIFT | 左Shift | 左Shift | 左Shift |
| GRAPH単独 | 左Alt | 左Alt | 左Option |
| KANA単独 | かなキー（International2） | 左Windowsキー | 左Command（⌘） |
| GRAPH ＋ KANA | LANG1（かな相当） | 半角／全角 | LANG1（かな相当） |
| GRAPH ＋ SPACE | LANG2（英数相当） | 半角／全角 | LANG2（英数相当） |

LANG1／LANG2や半角／全角の効果はホスト側の対応と入力設定に依存します。FM7モードのLANG1／LANG2についても、エミュレータ側での動作を保証するものではありません。

Windows・Macモードでは、KANA単独で日本語入力を切り替えることはできません。上表のGRAPHとの組み合わせを使用します。たとえばMacモードでコピー操作を行う場合は、KANA＋CがCommand＋Cに相当します。

## 6. キー割当

### 主なキー

| FM-7のキー | USBで送信するキー |
|---|---|
| 英字・数字 | 対応する英字・数字キー |
| ESC／TAB／SPACE | Escape／Tab／Space |
| RETURN・ENTER | Enter |
| BS | Backspace |
| PF1～PF10 | F1～F10 |
| CAP | Caps Lock |
| INS | Insert |
| DEL | Delete（前方削除） |
| HOME | Home |
| EL | Page Up |
| CLS | Page Down |
| DUP | End |
| ↑／↓／←／→ | 対応する矢印キー |
| BREAK | Pause（単独。Ctrlとの合成なし） |
| ¥ | JISの¥キー（International3） |
| テンキー0～9、演算子、小数点、Enter | 対応するテンキー入力 |
| テンキーの「=」 | Num Lock |
| テンキーの「,」 | 通常のカンマキー |

記号の表示はホストの配列設定に依存します。テンキーの「=」は文字の等号を送信しません。Num Lockの扱いはホストによって異なります。

PFキーから `AUTO`・`LIST`・`RUN` などの文字列を自動入力する機能はありません。また、変換・無変換・ろに相当する専用物理キーはありません。

### GRAPHを使う追加操作

| 操作 | 全モード共通の送信キー | 用途例 |
|---|---|---|
| GRAPH ＋ EL | F12 | fm7emulatorのメニューの表示・終了 |
| GRAPH ＋ DUP | F11 | F11に割り当てられた機能 |

追加操作中はGRAPH由来のAlt／Optionを除いて送信します。CTRLやSHIFTも押している場合は、それらの修飾は残ります。操作後は組み合わせたキーを離してください。

## 7. ランプ表示

| ランプ | 通常時の動作 |
|---|---|
| CAPS | ホストから通知されたCaps Lock状態に従う |
| かな（FM7モード） | ホストから通知されたNum Lock状態に従う。fm7emulatorがかな状態をこの通知で送る仕様に対応 |
| かな（Windows／Macモード） | ホストから通知されたHID Kana状態に従う |
| INSERT | 本基板では駆動しないため点灯しない |
| Pico本体のLED | ホストから通知されたScroll Lock状態に従う。fm7emulatorがINS状態をこの通知で送る仕様に対応（INSERTランプの代用） |

**Windows／Macでは、日本語入力中でもかなランプが点灯しない場合があります。** OSや入力ソフトがHID Kana状態を通知しない場合、入力状態とランプは連動しません。

起動時とモード切替時は、CAPS・かなランプがモード表示のために点滅し、その後ホストから通知された状態へ戻ります。点滅はモード表示であり、全キーの自己診断結果ではありません。

## 8. 同時押しの制限

標準ファームウェアは、修飾キーを除いて最大6つの異なるキーコードを送信します。これを超えると、通常のキー一覧の代わりにロールオーバー超過を通知します。キーを離して数を減らしてください。

ただし、**6キーまでのあらゆる組み合わせを保証するものではありません。** キーマトリクスの読み取りが曖昧になる組み合わせでは、誤入力を防ぐため直前の確定状態を維持します。この間、新しく押したキーが入らない、または直前のキーが押されたままに見えることがあります。いったんすべてのキーを離し、押す組み合わせを減らしてください。

BREAKは独立入力のため、マトリクスの曖昧さによる停止の対象外です。ただし、標準形式の6キー上限には含まれます。

NKRO版へ変更しても、キーマトリクス由来の制限はなくなりません。実機でのゴースト発生条件と全キーの同時押し特性は未確認です。

## 9. 困ったときは

| 症状 | 確認・対処 |
|---|---|
| USBキーボードとして認識されない | 通信対応ケーブルか、Picoへの装着・給電が正しいか確認します。診断版ではHIDキーボードになりません。通常版を書き込んでください |
| 書き込み後にMacから見えなくなった | USBを抜き差しします。ドック経由での書き込み後に再認識されなかった事例があります。必要ならホストへ直接接続して切り分けます |
| 認識するがキーが入らない | USBを外してからJ3の向きと挿し込みを確認します。特定キーだけの場合は診断版で押下・解放を確認します |
| 記号が刻印と異なる | ホストのキーボード配列・入力ソースを確認します。本機は文字列ではなくキーコードを送信します |
| KANAを押すとWindowsキー／Commandになる | Windows／Macモードの仕様です。日本語切替はGRAPHとの組み合わせを使用します |
| 日本語入力中にかなランプが消えている | 第7章を参照してください。ホストがKana状態を通知していない場合は連動しません |
| INSERTランプが点灯しない | Rev 0.5では未接続です。INS状態はPico本体のLEDで確認できます |
| テンキー「=」で等号が入らない | Num Lockに割り当てています。第6章を参照してください |
| 同時押しで入力が止まる・キーが残る | すべてのキーを離し、押す数や組み合わせを減らします。第8章を参照してください |
| モードが切り替わらない | ほかのキーを離し、CTRL・GRAPHを先に押してからPF1／PF2／PF3を押します。対応ファームウェアかも確認します |
| 文字が重複する・勝手に入力される | すべてのキーを離し、ケーブルとキースイッチの状態を確認します。続く場合は診断版で切り分けてください。Rev 0.5には第11章の未実装対策があります |

## 10. ファームウェアの更新

通常使用時に毎回行う必要はありません。更新作業には、このリポジトリとPlatformIOを利用できる開発環境が必要です。コマンドはリポジトリのルートで実行します。

### ブートセルモードでの書き込み

USBを外し、PicoのBOOTSELを押しながらUSBを接続して、書き込み可能な状態にしてから、.uf2ファイルをコピーしてください。.uf2ファイルは `pio run -e pico` でビルドすると `.pio/build/pico/firmware.uf2` に作成されます。

### コマンドによる書き込み

```sh
pio run -e pico -t upload
```

初回など自動書き込みができない場合は、USBを外し、PicoのBOOTSELを押しながらUSBを接続して、書き込み可能な状態にしてから再実行してください。書き込み後に認識されない場合は、USBを抜き差しします。

書き込み後はモード表示を確認し、必要なモードを選び直してください。フラッシュ全消去後など、有効な保存設定がない場合はFM7モードで起動します。

## 11. Rev 0.5の制約と検証状況

### 基板の制約

- INSERTランプは未接続です。
- J3の5V電源用デカップリングコンデンサ（100nF＋10µF）は未搭載です。
- SENSE0～6・BREAKの外付けプルアップ抵抗は未搭載で、Picoの内部プルアップを使用します。
- 抵抗の定数は基板に印字されていません。組立・修理は[設計仕様書の主要部品一覧](fm7-usb-keyboard.md#61-主要部品)と照合してください。

誤検出などの切り分けや部品の追加は、USBを外してから行ってください。回路変更の詳細は[設計仕様書](fm7-usb-keyboard.md)を参照してください。
